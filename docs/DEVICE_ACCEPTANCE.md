## 準備

1. Mac 與 Windows Chrome 登入同一 Google 帳號，確認書籤與擴充功能同步已啟用。回報只需「相同／不同」，不需提供帳號或登入資料。
2. 兩台都在 `chrome://extensions` 載入新版解壓後的 Boardmarks 資料夾，核對上方版本及 ID。
3. 若 Windows 尚無 Boardmarks 書籤根資料夾，先等待 Mac 的根資料夾出現在 Windows 的 Chrome 書籤管理員，再開始 Windows 工作台；不要在兩端同時建立兩份根目錄。
4. 開啟 Windows 新分頁，確認顯示同一工作區。若有新分頁變更提示，依 Chrome 介面確認使用 Boardmarks。
